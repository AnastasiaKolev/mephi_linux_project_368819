## Персональная страница

Файл:

```text
/home/user1/public_html/index.html
```

Содержимое:

```text
Hello from Student: 368819
```

Проверка:

```bash
curl http://localhost/~user1/
```

Ожидаемый вывод:

```text
Hello from Student: 368819
```

## Сеть

В `ip.out` сохранены результаты:

```bash
ip a
ip route show
```

Интерфейс получает адрес динамически по DHCP. В `ping.out` сохранён фактический результат проверки доступности `8.8.8.8` командой:

```bash
ping -c 4 8.8.8.8
```

## Файловая система

Для данных проекта настроено постоянное монтирование по метке тома:

```text
LABEL=MEPHI_DATA /data-mephi ext4 defaults 0 2
```

Настройка сохраняется после перезагрузки благодаря записи в `/etc/fstab`.

## Apache и mod_userdir

Apache используется как веб-сервер. Сервис включён в автозагрузку и обслуживает персональную страницу пользователя `user1` через URL:

```text
http://localhost/~user1/
```

Системные сообщения Apache сохранены в `httpd_logs`.

## Capabilities для tcpdump

Для запуска `tcpdump` обычным пользователем назначены capabilities:

```text
/usr/sbin/tcpdump cap_net_admin,cap_net_raw=ep
```

Результат сохранён в `getcap.out`.

## Политика паролей

В `/etc/security/pwquality.conf` установлено:

```text
minlen = 10
```

Для пользователя `user1` настроена смена пароля каждые 90 дней.

## Артефакты репозитория

- `history.out` — история выполненных команд
- `ip.out` — адреса интерфейсов и таблица маршрутизации
- `ping.out` — проверка доступности `8.8.8.8`
- `fstab` — копия `/etc/fstab`
- `passwd` — копия `/etc/passwd`
- `shadow` — копия `/etc/shadow` согласно требованиям задания
- `dnf.out` — история транзакций DNF
- `stat.out` — результат `stat /home/user1`
- `httpd_logs` — журнал Apache за последние 5 минут
- `getcap.out` — capabilities для `tcpdump`
- `pwquality.conf` — настройки качества паролей
- `index.html` — персональная web-страница
- `mephi-screenshot.png` — визуальное подтверждение работы Apache

> Примечание: файл `shadow` добавлен только потому, что он прямо указан в перечне обязательных артефактов задания. Репозиторий не следует использовать для хранения реальных учетных данных вне учебной среды.
