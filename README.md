# mephi-session-project-2026

Сессионный проект по дисциплине **«Администрирование рабочей станции под управлением ОС GNU/Linux (vo_HW)»**.

Студент: **368819**

## Что в репозитории

- `mephi_linux_project_368819.docx` — полный пошаговый отчёт и инструкция по выполнению задания
- `project_history.txt` — история выполненных команд
- `network_check.txt` — результаты ping
- `nginx_recent_logs.txt` — логи nginx
- `fstab.txt` — содержимое `/etc/fstab`
- `selinux_status.txt` — статус SELinux
- `file_contexts.txt` — SELinux-контекст каталога `/data/mephi-web`
- `tcpdump_capabilities.txt` — настроенные capabilities для tcpdump
- `permissions.txt` — права и владелец каталога `/data/mephi-web`
- `users_groups.txt` — пользователь `mephi-admin` и группа `mephi-devs`
- `index.html` — тестовая web-страница
- `curl_output.txt` — результат `curl http://192.168.1.100`
- `mephi-nginx-screenshot.png` — скриншот результата
- `tcpdump.rpm` или `tcpdump-*.rpm` — скачанный RPM пакет
